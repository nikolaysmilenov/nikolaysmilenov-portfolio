# Certificate images

Place certificate image files here using the filenames defined in `src/data/certificates.ts`.

Expected files:

- `introduction-to-cyber-security.png`
- `reconnaissance-fundamentals.png`
- `system-and-network-compromising.png`

Supported formats: `.png`, `.jpg`, `.webp` (update the filename in the data file if needed).

If a file is missing, the site shows a polished placeholder instead of a broken image.
